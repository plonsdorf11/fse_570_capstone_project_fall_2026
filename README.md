## Phase 1: Data Collection, Cleaning & Spatial Integration
This repository contains the Phase 1 deliverables for the FSE570 Capstone Project. The pipeline uses the **ASU Arizona Water Observatory (AWO) OGC API** (`https://arizonawaterobservatory.asu.edu/`) to programmatically ingest, clean, and spatially join:
- **ADWR Groundwater Well Registry & Measurements** (`ArizonaWaterWells`)
- **ASU Groundwater Basin Polygons** (`ASU_Groundwater_Basins_Aggregated_Grace`)
- **Active Management Area (AMA) Boundaries** (`Active_Management_Areas_2025`)
