# Arizona Water Conservation Platform (FSE570 Capstone Project)
**Team Adventurer:** Afshiya Roohi Shaik (`ashaik89@asu.edu`), Paul Lonsdorf (`tlonsdor@asu.edu`), Harshith Dharbi (`hdharbi@asu.edu`), Sneha Sai Kummara (`skummar3@asu.edu`)[cite: 1, 2]

## Phase 1: Data Collection, Cleaning & Spatial Integration
This repository contains the Phase 1 deliverables for the FSE570 Capstone Project[cite: 1, 2]. The pipeline uses the **ASU Arizona Water Observatory (AWO) OGC API** (`https://arizonawaterobservatory.asu.edu/`)[cite: 1, 2] to programmatically ingest, clean, and spatially join:
- **ADWR Groundwater Well Registry & Measurements** (`ArizonaWaterWells`)
- **ASU Groundwater Basin Polygons** (`ASU_Groundwater_Basins_Aggregated_Grace`)
- **Active Management Area (AMA) Boundaries** (`Active_Management_Areas_2025`)
